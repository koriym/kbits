# 1株で議決権50.1%——上場後のAnthropicは誰が支配し、その支配はいつ終わるのか

## 要約

### 二つの「1株」が握るもの

上場後のAnthropicの株式は、Class A（1株1票）、Class N（無議決権）、Class T、Class F、Class E、未指定優先株の6区分に分かれる。支配の中心はClass TとClass Fの各1株にある。

Class T 1株はLTBT（Long-Term Benefit Trust）が持つ。LTBTはデラウェア法上のnoncharitable purpose trustで、5名のTrusteeが運営する。Class Tにより、授権7名の取締役のうち4名のClass T取締役を選任・解任できる。配当や残余財産の権利はなく、日常の経営や戦略策定の権限もない。ただし合併や実質的全資産の売却は、過半がLTBT選任である取締役会の承認を要する。

Class F 1株は、募集完了の直前に、7名の共同創業者（Dario Amodei、Daniela Amodei、Tom Brown、Jack Clark、Jared Kaplan、Sam McCandlish、Christopher Olah）のみを構成員とするFounder LLCへ発行される。Class Fは株主総会の一般事項について、基準日時点の発行済株式の総議決権の50.1%を持つ。基準日ごとに再計算されるため、Class Aや議決権付き優先株の追加発行で希薄化しない。例示では、Class Aを100万株追加発行するとClass Fの票数は自動的に約1,004,008票増える。Class A全体は49.9%にとどまる。

会社はLTBTおよびFounder LLCとStockholders' Agreementを結び、両者は合わせて全取締役を選任できる。Class T以外の3席は、株主総会の過半を握るFounder LLCが事実上決める。IPO時点では、Class T枠がHastings、Narasimhan、Liddellと空席1、残り3席がDario Amodei、Daniela Amodei、Razaviである。

Benjamin Mannは創業時からの中核メンバーで共同創業者と呼ばれることが多いが、Founder LLCの構成員でもContinuing Founderでもないと脚注にある。

### Class A株主にできること、できないこと

Class A株主は取締役選任の結果に影響できない。例外は一つで、Continuing Foundersの過半がClass Fの投票先に合意できないとき、Class FはClass Aの賛否比率に比例して投票される。取締役会授権数の80%とTrusteeの80%が承認した定款改正には、Founder LLCがClass Fを賛成投票する義務を負う。

Class A株主の票が独立に意味を持つのは、Class Tの償還やLTBTの条件変更（Trust Amendment Threshold）と、Class F消滅後の定款改正に限られる。定款改正の要件はClass F Sunset前がClass AとClass Fの過半、Sunset後がClass A議決権の66 2/3%である。優先株の発行には取締役会80%に加え、Class F Sunset前はFounder LLCの同意が要る。会社はPBC（公益法人）であり、発行済株式の2%または時価200万ドルの少ない方以上を持つ株主は、デラウェア州法367条に基づき公益と株主利益の均衡義務の履行を求めて提訴できる。

Nasdaq上のcontrolled companyに該当する根拠はLTBTの取締役過半選任権のみで、Founder LLCの50.1%は挙げられていない。免除はNGC（指名・ガバナンス委員会）の独立性要件にのみ使う予定で、NGCはDaniela Amodei（議長）、Hastings、Razaviで構成される。

### Class Tはいつ終わるか——承認がなければ終わらない

Class T Sunsetは時間の経過や特定の事象では起きない。Class Tの無償償還とLTBTの条件変更には、次の三段階の閾値のいずれかが要る。

- Trusteeが賛成する場合: 取締役会授権数の80%かつ在任Trusteeの80%。
- Trusteeが反対し、Class Fが存続する場合: IPO完了から3年まではContinuing Founders全員一致によるClass F、Class E投票の過半（定足数40%）、Class A投票の過半の三重承認。期限のない経路は、Continuing Foundersの66 2/3%、Class E投票の75%（定足数過半）、Class A投票の過半。
- Class Fが消滅した後: Class A発行済株式の85%。

Class Tは同じ承認で譲渡もでき、譲渡先に別途の制限はない。原文は「長期的な柔軟性を保つため」の意図的な設計だと述べる。

Class T取締役4席のうち1席（Specified Class T Director）の指名・解任・指定変更にはNGCの同意が要り、15日以内に同意がなければClass E株主の投票に付される。初代はLiddellである。Class T取締役の指名・解任やTrusteeの任免はNGCへの30日前通知を要するが、通知期間は放棄でき、正当事由による解任にNGCの同意は不要である。

Trusteeは5名定員の自己補充型だが、IPO時点では4名（Shah議長・2023年6月〜、Fontaine・2025年4月〜、Bernanke・2026年6月〜、Stubbs・2026年10月〜）で1席が空席である。原文は、Trusteeの発掘、面接、選定で会社幹部と密接に協働してきたと記す。報酬は各年$400,000の現金（議長加算$25,000）で、会社の利益や行動に連動せず、Trusteeは自社証券を保有できない。LTBTの資金は会社が出し、2026年1〜9月に$8,425,213を支払った。LTBTは連結VIEとして会社の貸借対照表に含まれる。2026年8月には、Trustee FontaineがCEOを務めるCNASへ会社が$450,000を寄付した。

Stockholders' Agreementで会社は清算事由、取締役会が定めた能力閾値を超えるAIモデルの支配権移転、50%以上の売却などについてLTBTへの事前書面通知を約束する。同意権ではなく通知であり、期間は放棄できる。

### Class Fはいつ終わるか——人が減れば自動で終わる

Class F Sunsetは、(i) Continuing FoundersのSupermajorityによる償還合意またはFounder LLCの解散でClass Fがなくなる時、(ii) Class F Transition Periodの完了、のいずれか早い方である。Supermajorityは「総数マイナス1」で、3名未満なら全員一致となる。

Transition Periodは、Continuing Foundersが90日連続で3名未満になった時点で始まり、450日で完了する。期間中に後任を入れても発動事由は治癒せず、延長もされない。完了時にClass FとClass Eは無償で償還される。

Continuing Founder（当初7名）の資格は、辞任、死亡・無能力、正当事由（競業行為を含む）による除名、Supermajority承認の休職のほか、IPO完了時点で保有するClass A（オプション・RSU含む）の2%未満しか持たなくなった時に失われる。各創業者は個人持分の80%を慈善に充てると表明しているが、20%が残るため下限には触れない。死亡・無能力時の後任構成員の受け入れはIPO完了から10年までである。

Class Fの投票先はContinuing Founders 1人1票の過半で決まり、各創業者が個人で持つClass A株の投票は拘束されない。

### 終わった後に支配は誰へ渡るか

二つのサンセットは非対称で、Class Tは承認がなければ永続し、Class Fは人の離脱で自動的に消える。

Class Fが先に消えてClass Tが残る場合、LTBTは取締役過半の選解任権を保ったまま、Specified Class T Directorの手続きの拘束から外れる。同時に取締役会は毎年改選から3クラス3年任期の期差任期へ移行し、定款の一定条項の改正にはClass A議決権の66 2/3%、Class Tの償還には発行済の85%が要る。取締役会の定員もClass T Sunsetまで取締役会80%の承認なしに変えられない。創業者支配の終わりは、Class A株主への支配の移転ではなく、LTBT支配の固定化を意味する。

Class Tが先に消えてClass Fが残る場合、Founder LLCが全取締役の選任を含む株主総会の全事項を決める。

株主の書面同意の記述には幅がある。リスク要因の節はClass F Sunset後に書面同意が禁止されるとし、ガバナンスの節はClass FまたはClass Tが存続する限り取締役の選解任を含む一定事項を書面同意で決められるとする。Class Tが残る場合の扱いは本文だけでは定まらない。

### Class E——緩衝材としての従業員株

Class Eは共同創業者を除く従業員に、勤続6か月ごとに1株、また寄付を誓約したClass A株1株につき1株発行される。配当も残余財産もなく、議決権は保護的事項に限られる。退職後は毎年半分ずつ、死亡・無能力・懲戒解雇・直接競合への就業、Class F消滅時には全部が無償償還される。Class T償還のクラス別経路とSpecified Class T Directorの人事で、Class Eは創業者とLTBTの間の裁定者になる。ただし発行時期は未定で、2026年9月30日時点のプロフォーマでは発行済0株である。この期間にClass E投票を要する手続きがどう機能するかは本文に記述がない。

## 論評

一次資料としての価値は、LTBTと創業者の関係が定款と契約の条文として数字つきで確定した点にある。50.1%の再計算方式、80%と80%、IPO後3年で消える全員一致の経路、85%、90日と450日、2%、10年、15日と30日。これらは今後の変更を測る物差しになる。

読み方の限界は三つある。第一に、本ドラフトは発行済株式数が空欄で、Class A株主の構成比は算出できない。第二に、Founder LLC Agreementの「cause」や休職の定義は本文に要約しかなく、原契約の確認が要る。第三に、LTBTの独立性は原文の記述自体が二面的である。「独立した機関」と書く同じ節が、Trustee選定で会社幹部と密接に協働してきたこと、Trustee任免にNGCへの通知が要ること、LTBTの費用を会社が負担し連結していることを開示している。Trustee4名の年間報酬の合計は算出値で$1,625,000であり、2026年1〜9月の支払$8,425,213との差の用途は本文に説明がない。

5年後に確かめるべきことは明確である。Trustee5席の顔ぶれと空席の充足、Specified Class T Directorの交代、Continuing Foundersが7名から減ったか、IPO後3年で消える全員一致経路が使われたか、Class Tの譲渡や償還が提案されたか、Class Eがいつ誰に発行されたか。原文自身が「公開企業に直接の前例がない」と述べる構造の出発点として、この文書はそれらの基準値を与える。
