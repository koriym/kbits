# 公益株5%と寄付の議決権——Anthropicは『公益』を株式と損益のどこに書き込んだか

**著者:** Anthropic, PBC  
**公開日:** 2026年10月26日  
**ソースURL:** [Anthropic, PBC - Form S-1](https://www.sec.gov/Archives/edgar/data/2130357/000162828026067168/anthropicpbc-sx1.htm)

## 要約

Public Benefit Corporation（PBC）の「公益」は、定款の目的条項に書けば終わる言葉ではない。Form S-1を読むと、Anthropicはそれを三つの場所に数字として書き込んでいる。株数（公益子会社への拠出株）、費用（従業員寄付のマッチング）、議決権（創業者の寄付誓約と寄付先からの委任状）である。この三つを並べると、経済的な持分は会社の外へ向かう一方で、議決権は会社と経営者の側に残るという共通の形が見えてくる。

### 株数：議決権のないClass N株で実装された5%

会社は募集に向け、Class N普通株846,840,960株を完全子会社Anthropic Public Benefit Fundに拠出したと記載する。これは2026年6月30日時点の完全希薄化後株式数の5%に当たり、Amazonが保有する転換社債の全額転換を仮定した数字である。2026年10月には、公益目的で新設した完全子会社へ最大8億4,680万株のClass Nを発行することを株主が承認している。単純に逆算すると、分母となる完全希薄化後株式数は約169億株になる（算出値）。

Class Nという株式の性質がここでは重要になる。Class Nは議決権を持たず、経済的権利はClass Aと同等である。登録売出、公開市場での売却、または各株式クラスの9.99%超を実質保有しない非関連の第三者への譲渡が行われた時点で、1対1でClass Aに自動転換する。つまり、Fundが株式を保有している間、その株に票はない。票が生まれるのは、株が外部へ売られて初めてである。

Fundの保有株は第三者へ譲渡・寄付され、登録公募や私募で売却され得ると会社は明記する。ガバナンス構造が承認されるまで配分は取締役会が決め、その後は指定マネージャーに移る。初期マネージャーはDario Amodei、Daniela Amodei、Jack Clark、Neil Shahの4名である。Shahは取締役会の過半数を選任するLong-Term Benefit Trustの議長を兼ねる。

追加拠出の枠組みも株価に連動する。IPO価格を起点に、直前のマイルストーンから株価が50%上昇するごとに、取締役会の裁量で発行済株式の最大2%を追加拠出できる。判定条件は、直近120営業日のうち90日以上で終値が基準を超え、かつ直前10営業日の平均終値も超えることである。IPO価格の1.5倍、2.25倍、約3.4倍と到達するたびに枠が開く計算になる（算出値）。追加拠出は義務ではなく裁量であり、リスク要因の章は、こうした公益目的の発行が「substantial in scale」であり今後大幅に拡大する見込みだと述べ、既存株主に大幅な希薄化をもたらし得るとも書いている。

### 費用：株価を入力とする寄付マッチング

従業員は株式報酬の一部を慈善目的に誓約でき、会社はそれをClass N株でマッチングする。この負債は、会社の株価を主な入力として公正価値で測定される。財務諸表の注記は、一般管理費（G&A）が「主に寄付マッチング債務から成る」と説明しており、G&Aの第一項目がこの制度である。

数字を追うと規模が分かる。2025年末時点の寄付マッチング負債は5億4,100万ドルであった。2025年通期の総営業費用126億4,500万ドルに対して約4%、G&A 11億2,300万ドルのほぼ半分に相当する（いずれも算出値）。2026年第1四半期には公正価値の変動1億2,600万ドルを認識したうえで、3,060万株のClass Nを発行して決済した。発行額は6億6,700万ドルで、1株あたり約21.8ドルに相当する（算出値）。2026年第3四半期には、8月に行われた従業員寄付に対するマッチング債務について、初期認識と公正価値変動を合わせて20億ドルを費用計上し、10月に約2,800万株のClass Nを発行した。この20億ドルは第3四半期末時点の測定値であり、決済株数との単純な割り算は概算にとどまる。

2025年の5億ドル規模から2026年第3四半期の20億ドルへの増加は、参加者の増加と株価の上昇の両方を反映し得るが、S-1は内訳を示していない。確認できるのは、公益の費用が株価と連動して膨らむ構造になっていることである。なお、会社は寄付マッチング参加者のために株式の評価レポートを取得している。両Amodeiはこの制度に参加していないが、同じレポートを別途の慈善寄付の税務申告に使用した。費用の按分額は一人625ドルである。

### 議決権：誓約は撤回可能で、委任状は撤回不能

共同創業者7名は、個人持分の80%を慈善目的に充てると誓約している。S-1はこの誓約を「voluntary, revocable」であり、法的拘束力のある義務ではないと明記する。誓約が実行されても、Founder LLCを通じた投票支配は、各創業者が最低保有条件を満たす限り変わらない。その条件は、IPO完了時に保有するClass A株（オプションやRSUを含む）の2%以上を保有し続けることである。80%を手放しても20%が残り、下限の10倍に当たる。原文自身が、経済的持分は減るのに投票支配は不変であるため、創業者と他の株主の利害の整合が低下し得ると述べている。

寄付先の側では、委任状の設計が逆の性質を持つ。Dario Amodeiは、Daffy Charitable FundとDechomai Asset Trustという二つのdonor-advised fund（DAF）が保有する株式について、「sole and absolute discretion」で議決する不可撤回の委任を受けている。Daffy Charitable Fundとの契約日は2025年10月6日、Dechomai Asset Trustとは2024年12月20日で、両DAFは会社または株主から直接株式の寄付を受けるmaster donation agreementを会社と結んでいる。2026年9月30日時点で委任対象は4,621,120株であり、Dario本人、家族、関係者が寄付した株式は対象から除外される。取締役会は委任先を別の個人に変更できる。

誓約は撤回できるが拘束力がなく、委任は撤回できないが票を経営者に集める。他者が慈善目的で手放した株式の票が、取締役会が変更できる委任先一人の裁量に入る構造である。従業員については、寄付を誓約したClass A株1株につきClass E株1株が付与されるが、Class Eが票を持つ事項は限定され、この機構の詳細は別稿に譲る。

Fundの株もマッチングの株もClass Nであり、保有中は票がない。外部に売却されてClass Aに転換しても、Founder LLCのClass F株が株主総会一般事項の議決権50.1%を固定で持つため、希薄化を受けるのはClass A株主の側である。

### 衡量の基準：第三者基準を採らず、断念した収益は会社が列挙する

PBCの取締役は、株主の金銭的利益と公益を衡量する義務を負う。Anthropicの定款と付属定款は、公益の達成度を客観的な第三者基準で測ることを求めない。基準は取締役会が定め、会社は目標と基準が定性的なものになると見込んでいる。測定対象は五つのミッション柱で、AI安全の技術的解決、法で裏打ちされた普遍的実践、民主主義と国際安定、繁栄と人間の開花、便益の共有である。デラウェア州法が求める隔年報告はウェブサイトで公開される。衡量義務の履行を求めて提訴できるのは、発行済株式の2%以上か時価200万ドル以上を保有する株主に限られ、会社は判例が乏しいと認める。さらに、衡量義務の不履行は、取締役の免責が外れる善意の欠如や忠実義務違反に当たらないと定款等で定めている。

その代わり、収益を断念した判断は会社自身が列挙する。使用ポリシーで完全自律兵器と大規模監視（国内の大量監視を含む）への利用を禁じ、収益を生み得る用途を拒否してきたことで、商業的・財務的な不利益が「has had」、つまり既に生じたと述べる。Mythosモデルを当初はProject Glasswing経由のゲート付き研究プレビューに限定したこと、画像・動画生成モデルを意図的に開発せず計算資源を研究と安全性に振り向けたことも、同じ文脈に置かれる。いずれも金額の開示はない。

## 論評

この文書の価値は、PBCの「公益」が初めて株数と費用と契約の形で確定した点にある。Claude憲章の文面からは倫理的な緊張を読むことはできても、公益がどの株式クラスで実装され、誰が票を持つかは見えなかった。S-1は、公益株が無議決権のClass Nであること、寄付マッチングが株価連動のG&A費用であること、寄付先からの委任状が撤回不能でCEOに集まることを、一次資料として示している。

読み方には限界がある。第一に、Fundは完全子会社であり、株式が第三者へ移るまで経済的持分は会社の外に出ていない。「5%を公益に充てた」という表現は、現時点では拠出であって移転ではない。第二に、拠出株の会計上の扱い、すなわち発行済株式数やEPSの分母にどう反映されるかは、本稿が依拠した範囲では確認できなかった。第三に、5%の分母はAmazon転換社債の全額転換を仮定しているが、Amazonの所有上限により一部は募集直前に転換できない。したがって、IPO時点の実際の発行済株式に対する比率は5%と一致しない可能性がある。第四に、2026年9月に10対1の株式分割が行われており、文書中の株数と単価がどの基準で表示されているかは章ごとの照合を要する。

5年後の比較基準として残すべき数字は三つある。初期拠出の846,840,960株と、50%上昇ごとに最大2%という追加枠は、実際に追加拠出が実行されたかを検証する基準値になる。80%誓約が法的拘束力を持たず、委任状が自己寄付分を除外しているという条項は、後年の寄付実績と議決権の帰属を照合する出発点になる。そして、公益の測定が定性的で隔年報告に委ねられ、提訴資格が2%または200万ドルに限られている事実は、PBCの衡量義務が将来争われた際に最初に参照される条件である。公益を数字で読むなら、この三つを起点にするのがよい。
